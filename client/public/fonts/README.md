# Severance fonts

These self-hosted Latin WOFF2 files are copied from the
[`@fontsource/orbitron`](https://www.npmjs.com/package/@fontsource/orbitron) and
[`@fontsource/chivo`](https://www.npmjs.com/package/@fontsource/chivo) packages.
Both typefaces are licensed under the SIL Open Font License 1.1; see
`OFL-Orbitron.txt` and `OFL-Chivo.txt`.

- Orbitron: `orbitron-latin-{400,500,600,700}-normal.woff2`
- Chivo Regular: `chivo-latin-400-normal.woff2`

The font files are served locally from `/fonts/`; they are not runtime package
dependencies and do not use a CDN.
